# AI Mock Interviewer

A web-based mock interview tool that simulates real software engineering interviews using AI. It generates role-specific questions, evaluates your answers, and gives structured feedback, so you can practice anytime without needing a human interviewer.

---

## What It Does

- Generates software engineering interview questions based on the topic or role you select
- Accepts your answers and evaluates them using AI
- Gives structured feedback on correctness, depth, and areas to improve

## Getting Started

````bash
git clone https://github.com/your-username/ai-mock-interviewer
cd ai-mock-interviewer
````

Add your Gemini API key to a `.env` file:

````
GEMINI_API_KEY=your_key_here
````

Then open `index.html` or run the backend server as needed.
